# SOP Writing Checklist

-   [ ] Purpose is clear.
-   [ ] Scope and exclusions are defined.
-   [ ] Process owner is identified.
-   [ ] Required roles are identified.
-   [ ] Prerequisites appear before steps.
-   [ ] Actions are in logical sequence.
-   [ ] Responsibility is clear.
-   [ ] Decision points state condition and action.
-   [ ] Common exceptions are addressed.
-   [ ] Escalation routes are identified.
-   [ ] Systems, forms, and related documents are accurate.
-   [ ] Required records are identified.
-   [ ] Retention statements come from applicable requirements rather
    than guesswork.
-   [ ] Ambiguous language is removed.
-   [ ] Links and references are checked.
-   [ ] Template placeholders are removed.
-   [ ] Procedure has been compared with actual practice.

# SOP Builder Toolkit

Version 1.0.0

A ready-to-customize toolkit for creating, reviewing, approving,
maintaining, and retiring standard operating procedures and work
instructions.

## Contents

**Templates:** SOP master, short-form SOP, work instruction, process
overview, roles and responsibilities, approval record, change request,
periodic review, and document retirement.

**Registers:** SOP inventory and document control register in CSV
format.

**Guides:** SOP lifecycle, SOP writing, naming and numbering, writing
checklist, review checklist, and implementation checklist.

**Example:** A completed fictional SOP showing how the system can be
used.

## Quick start

1.  Read `LICENSE.txt` and `DISCLAIMER.md`.
2.  Read `guides/SOP_LIFECYCLE_GUIDE.md`.
3.  Select the appropriate template.
4.  Replace all bracketed placeholders.
5.  Adapt approval, retention, access, and review requirements to your
    organization.
6.  Review the completed document before use.
